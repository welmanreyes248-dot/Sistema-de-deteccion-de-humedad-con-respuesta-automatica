# Sistema de detección de humedad con respuesta automática

## Descripción
Este proyecto consiste en un circuito realizado en Tinkercad utilizando Arduino UNO y un sensor de humedad para detectar cambios en el suelo.

## Materiales utilizados
- Arduino UNO
- Sensor de humedad
- Servomotor
- LED
- Resistencia
- Protoboard
- Cables de conexión

## Funcionamiento
El sensor envía lecturas al Arduino. Cuando el valor es menor que 400, el LED se enciende y el servomotor gira a 180 grados. Si el valor es igual o mayor que 400, el LED se apaga y el servomotor regresa a 0 grados.
